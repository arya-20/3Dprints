About the work

Process

Each piece starts as a model, gets sliced for the material, then is printed, cleaned up and checked before it is photographed for this page.

Materials

Mostly PLA for detailed models and display pieces, with PETG for parts that need to take heat or knocks.

Commissions

If you have something in mind, a part, a model or a gift, send a short description with the size and color. I will reply with whether it is a good fit and how long it would take.
